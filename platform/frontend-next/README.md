# NetOps UI (Next.js + Tailwind)

Interface científica em Dark Mode, densa em informações, com módulos:
- Dashboard (Observabilidade)
- Topologia (React Flow)
- Experimentos (templates + wizard 3 etapas)
- Lab Low-Code (node editor)
- Configurações (auto-discovery simulado)
- Monitor (stream)
- Histórico (auditoria + JSON expandível)

## Requisitos

- Node.js 20+ (recomendado) e npm.

## Rodar localmente

```bash
cd platform/frontend-next
npm install
npm run dev
```

Acesse: http://localhost:3000
